# Gramseba Investor Render
Render Web Service. Build: npm install. Start: npm start.
Environment variables: ADMIN_EMAIL, ADMIN_PASSWORD, ADMIN_SECRET.
For persistence, attach a Render persistent disk and set RENDER_DISK_PATH=/var/data.
This version uses manual bKash/Nagad/Rocket/Bank payment verification via Transaction ID. Review applicable laws before accepting real investment funds.
